# La API es NestJS con oRPC, y Zod en `packages/contracts` es la única validación

`apps/api` es NestJS 11 con `@orpc/nest` (`@Implement` del contrato) y `@jperezmart/nest-mongodb` sobre el driver `mongodb`, sin Mongoose: los schemas Zod del contrato son la única validación, la lógica va en `*Service`, el acceso a Mongo en `*Persistence` y la salida la valida oRPC ([ADR 0005](0005-errores-y-salida-en-orpc.md)). Sustituye a la decisión inicial de quedarse en Express (2026-06-13), que se abandonó en julio de 2026 para alinear la API con la arquitectura de referencia. Mongoose se descarta porque sus schemas y los de Zod acaban desincronizados y sus hooks esconden lógica.
